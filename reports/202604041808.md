```

→ 하지만 민간 피해 → 역효과 우려
```

```
✅ 완전 봉쇄는 아직 아님
```

## 2. 미국 지상군 파견 가능성

### 결론: 매우 낮음 (5~10%)

**지상군 파견 안 하는 이유:**

```
1️⃣ 트럼프의 역사적 입장
├─ "불필요한 해외 지상전 안 한다" (공약)
├─ 이라크·아프가니스탄 실패 학습
└─ "빠른 공습 + 압박" 전략 선호

2️⃣ 미국 여론
├─ 지상전 절대 반대 (70%+)
├─ 미군 인명 피해 = 정치적 자살
└─ 2028년 재선 고려

3️⃣ 현재 전략이 충분
├─ 공중 타격으로 이란 인프라 파괴 중
├─ 경제 제재로 이란 경제 압박
└─ 협상 병행 중

4️⃣ 지형·병참 문제
├─ 이란: 산악 지형 (지상전 불리)
├─ 이란군: 100만 명+ (대규모 저항 예상)
└─ 물자 보급선 확보 어려움
```

**지상군 파견이 가능한 예외 상황:**

```
❗ 미군 조종사 포로 상황 악화
   └─ 구출 작전 → 특수부대 투입 가능

❗ 이란 핵무기 완성 직전 신호
   └─ 핵시설 파괴 위한 지상 침투 가능

❗ 호르무즈 완전 봉쇄 + 국제 연합 요청
   └─ 해협 개방 작전에 해병대 투입 가능

현실적 평가:
"지상군보다 미사일·공습·특수부대로
 목표를 달성하려 할 것"
```

## 3. 4월 6일 협상 기한: 이틀 남음

### 현재 협상 상황

```
트럼프의 15개 조항 평화안:
├─ 이란에 전달: ✅
├─ 이란 공식 수용: ❌
├─ 이란 공식 거부: ❌ (애매한 입장)
└─ 협상 채널: 열려있음

새 변수:
├─ 미군 전투기 격추 → 미국 강경화
├─ 이란 민간 피해 → 이란 강경화
└─ 후티 참전 → 협상 더 복잡

시간: 4월 6일까지 약 48시간
```

### 시나리오

```
✅ 협상 타결 (확률 20%):
├─ 급격히 낮아짐 (미군 격추 여파)
├─ 유가: $85~95 복귀
├─ 원달러: 1,450원대
└─ 코스피: 급등

⚠️ 또 연장 (확률 45%):
├─ "협상 진전" 명분으로 재연장
├─ 유가: 현 수준 유지
└─ 불확실성 지속

❌ 타격 재개 (확률 35%):
├─ 미군 격추 = 강경 대응 압박
├─ 유가: $130~150 급등
├─ 원달러: 1,550~1,600원
└─ 한국 증시: 급락
```
